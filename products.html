CBT Pro
"Built by a tutor, for tutors. Not with web dev skills — with clear thinking and AI leverage."

CBT Pro is a full Computer-Based Testing platform for Nigerian schools — built entirely on an Android tablet using Acode editor, with zero budget, zero web development background, and zero cost to schools. It is the proof of concept that defines what AI-Augmented Solutions Development actually means in practice.

Key Features
✓ 7-column CSV question upload — no manual entry required
✓ Timed exam sessions with countdown and auto-submit
✓ Per-student question AND option randomisation (anti-copy)
✓ Anti-cheat tab-switch detection with configurable tolerance
✓ Flag-for-review — revisit questions before final submit
✓ Auto-marking + result certificate with WhatsApp share
✓ 4-tab teacher analytics: Overview · Question Analysis · Student Comparison · Trends
✓ Optional Gemini AI explanation per question
